# Tetris Game

Этот репозиторий содержит простую реализацию игры «Тетрис» на Python с использованием `pygame`.

## Описание файла

- `main.py` — основной файл проекта.  
  В нем находятся:
  - шаблоны фигур (тетромино);
  - классы `Shape`, `Board`, `TetrisGame`;
  - логика управления, отрисовки и подсчета очков;
  - запуск игры через функцию `main()`.

## Дополнительные файлы

- `PressStart2P-vaV7.ttf` — шрифт интерфейса.
- `OIP.png` — изображение для стартового экрана.
- `TETRIS A.mp3` — фоновая музыка.
